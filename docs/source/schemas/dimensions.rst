dimensions.json
===============

:asset:`Source reference <dsconfigs/dimensions.json>`

The dimensions configuration allows for overriding a dimensions proeprties as defined within the registries. Sometimes the registered information is incorrect, or the dimension is unqiue in some way that causes effects generated by
Dynamic Surroundings to not make sense. Such dimensions could include mining dimensions with higher sealevels or those that are entirely enclosed.

.. code-block:: JSON

    {
        "dimId": "resource location ID",
        "seaLevel" : null,
        "skyHeight": null,
        "cloudHeight": null,
        "alwaysOutside": null,
        "playBiomeSounds": null,
        "compassWobble": null,
        "particleWeather": null,
        "simulateWind": null,
        "groundFog": null
    }

.. list-table:: Dimension Configuration
    :widths: auto
    :align: center
    :header-rows: 1

    *   - Property
        - Value Type
        - Comment
    *   - dimId
        - ResourceLocation
        - The :term:`resource location <Resource Location>` ID of the dimension. It is a required property.
    *   - seaLevel
        - Integer
        - The block Y level that is considered sea level. It is used when calculating whether the player is under ground. Default is not specified, meaning Dynamic Surroundings will rely on the dimension information defined in the registries. For superflat worlds the default is ``-60``.
    *   - skyHeight
        - Integer
        - The block Y level that is considered sky. It is used when calculating the threshold of the virtual sky biome. Default is the world height of the dimension as defined in the registries.
    *   - cloudHeight
        - Integer
        - The block Y level that is considered clouds. It is used when calculating the threshold of the virtual cloud biome. Default is the height at which Minecraft renders the dimension's clouds (``192`` for the Overworld). For dimensions without clouds, such as the Nether and End, the default is a height that is never reached, so the player is never considered to be in the clouds. (*Default changed in 1.21.1-0.4.6; previously half the sky height*)
    *   - alwaysOutside
        - Boolean
        - Indicates if sound effects processing should consider this dimension as always being outside. Helps with defining biome sounds for dimensions that are enclosed. Default is ``false``.
    *   - playBiomeSounds
        - Boolean
        - Indicates if any biome sounds should be generated in the dimension. Default is ``true``.
    *   - compassWobble
        - Boolean
        - Indicates if the compass and clock overlays should cause wobbling for the dimension. Default is based on whether the dimension is considered natural or not. In Vanilla, compass wobbling occurs when in the Nether or End. (*Added 1.21.1-0.4.2*)
    *   - particleWeather
        - Boolean
        - Indicates if Dynamic Surroundings' particle rain, snow, and dust storms should replace the dimension's weather rendering. Default is ``true`` for dimensions that use Minecraft's own Overworld, Nether, or End rendering, and ``false`` for dimensions that provide their own (including modded dimensions that customize vanilla rendering), so that modded weather is not hidden. (*Added 1.21.1-0.4.7*)
    *   - simulateWind
        - Boolean
        - Indicates if simulated wind blows in the dimension. Wind drifts the weather, mist, steam, smoke, and flames. Default is ``true`` for dimensions that have sky light, ``false`` otherwise. (*Added 1.21.1-0.4.7*)
    *   - groundFog
        - Boolean
        - Indicates if ground fog can form in the dimension, in the biomes that are configured for it. Default is ``true`` for dimensions that have sky light, ``false`` otherwise. (*Added 1.21.1-0.4.7*)

Multiple rules can be defined for the same dimension, such as from different mods or resource packs. A rule only changes the properties it specifies, so a property that is left out
does not undo a value set by another rule. If more than one rule sets the same property, the last one loaded is used.

The following is an example of the rules Dynamic Surroundings provides for the Nether and End:

.. code-block:: JSON

    [
        {
            "dimId": "minecraft:the_nether",
            "seaLevel": 0,
            "alwaysOutside": true,
            "simulateWind": false,
            "groundFog": false
        },
        {
            "dimId": "minecraft:the_end",
            "seaLevel": 0,
            "cloudHeight": 128,
            "alwaysOutside": true,
            "simulateWind": false,
            "groundFog": false
        }
    ]
