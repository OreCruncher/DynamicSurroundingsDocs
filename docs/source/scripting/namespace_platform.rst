*platform* Namespace
====================

*Added in 1.21.1-0.4.3*

These functions are related to the runtime environment of the Minecraft client.

.. js:function:: Boolean platform.isModLoaded(String modId)

    Indicates whether the specified mod is loaded.

    :param modId: The ID of the mod to test for
    :type modId: String
    :return: ``true`` if the mod is present, ``false`` otherwise
    :rtype: Boolean
